# 使用说明

## 第一次使用

Mac（13.5+）推荐在新项目目录执行 `bash scripts/start-local.sh`，自动准备便携运行时并启动免 Docker 个人版。`启动 AI Universe.command` 也使用这个模式；若系统拒绝双击，可用前述 Bash 命令运行。已有 Python/Node 的开发模式仍可执行 `./scripts/start.sh`，在本机浏览器打开端口 3000。创建用户名、至少 12 位密码和公司名称。系统只允许一次所有者初始化；不开放新用户注册。所有者可通过左侧公司选择器建立或切换多个公司。

## 配置团队

“AI 员工”预置 Atlas、Emma、Alex、Sophia、Mike、Lily、David、Noah，分属五个部门。可新增部门、修改部门说明，编辑员工的岗位、职责、目标、技能、工具权限、汇报对象。汇报关系不能成环。

“自然语言招聘”当前是本地字段解析，支持明确句式 `创建员工 Iris，岗位：法律顾问，负责合同审查`；不声称已启用自由语义理解。创建后可再编辑完整配置。文档工具权限控制生成文件；分析权限控制文本和 CSV 统计。系统未授予 shell、任意网络或用户代码执行权限。

## 创建任务

在任务中心或驾驶舱点击“创建任务”：

1. 填写任务目标、原始材料、验收标准。
2. 选择执行员工与可选项目。
3. 选择执行提供方。`本地规则` 不产生模型费用，只处理已提供的文本/CSV；`ChatGPT 计划` 目前明确等待授权，不会调用普通付费 API。
4. 选择交付格式：Markdown、Word、Excel、PPT、PDF、Python 文件、HTML 或网页 ZIP。
5. 设置最大执行次数、截止时间与前置依赖。付费预算固定为 0。
6. 提交后后台自动调度，无需保持某个聊天窗口开启。

老板直接指挥会创建单个任务。本地“自主组织”采用三员工模板：材料整理与材料复核并行，第三名员工接收两份成果后汇总。它使用真实独立运行记录和文件，不是聊天演示；但任务拆分由规则生成，尚没有模型自主规划能力。

## 审核、退回和恢复

完成工具执行的任务进入“待办审批”。先查看输入、验收标准、运行记录和真实文件，然后选择通过或退回。退回必须写修改意见；重新执行会保留旧版本并生成新版本。

任务详情支持暂停、取消与恢复。父协作任务的暂停/取消会传递到仍未完成的子任务，已完成子任务保留。不重置已消耗的轮次，避免借助恢复无限循环。单任务/协作总次数上限耗尽后，需要建立新任务；公司日额度调整后可以恢复因日额度暂停的任务。

免 Docker 本地版保持终端开启，按 Ctrl+C 停止，数据保留在用户 Library/Application Support/AI Universe/local/data 中。

容器版使用 `bash scripts/stop-docker.sh` 停止，关闭终端不会停止容器或删除数据。开发模式仍用 Ctrl+C 停止。

后台进程被异常中断时，任务在租约过期后恢复（默认最长 120 秒），旧运行记为“中断恢复”。正常停止启动脚本会等待进程清理；不要把动画或打开端口当作任务完成依据。

## 成果资料库

成果均为实际生成的本机文件，包含版本、大小、SHA-256 和预览。在线预览以可读文本展示内容；下载获得真实格式文件。当前不提供 Office 原生排版的浏览器渲染。HTML 总是作为附件下载，避免执行不受信任内容。

本地生成的 Python 文件是输入统计工具，网页 ZIP 是材料展示项目；不会冒充模型已编写任意业务系统。需要完整智能内容或代码生成时，等待官方模型授权接通后再验证。

## 长期记忆与知识

支持公司、部门、员工、项目四种范围。每条记忆填写内容、来源、可信度和适用对象。只有你勾选“人工核实”的记忆才会注入匹配范围的任务输入。未经核实的记忆仍可保存查看，但不会用作已确认事实。删除记忆只影响未来任务，历史运行的已保存输入仍可用于审计。

## 虚拟办公室

桌面端支持旋转、缩放和点击工位标记进入员工档案；手机仍优先提供员工、任务、审批和成果管理。无 WebGL 2 时显示能力提示和员工列表。

当前楼层含大厅、开放工位、咖啡台、休闲区、书架、会议区和玻璃隔断。写实人物与生活动作尚未制作。员工档案中的生活状态可单独保存，不能把“喝咖啡”或“敲键盘”当成工作执行/完成；实际任务状态始终来自后端。

## 成本与数据

调用页展示所有已登记执行单位、结果和零费用记录。公司设置可调整日额度、并发、最大轮次、超时。没有已启用的付费提供方，也不会自动切换。

免 Docker 本地版使用用户目录中的 SQLite 与成果目录。开发模式数据持久保存于本地 PostgreSQL 命名卷和 `.data/artifacts`；容器版使用独立项目的数据库和成果命名卷。`Ctrl+C` 不删除数据。备份时同时保留数据库、成果文件和 `.env`；不要运行 `docker compose down -v` 来停止普通工作。
