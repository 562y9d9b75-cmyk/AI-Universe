## 已实施的边界

`backend/app/providers.py` 提供可扩展的 `execute(Context, operation)` 提供方接口。`chatgpt_plan` 适配器明确抛出 `AuthorizationRequired`，运行器记录 `blocked_auth` 并暂停，不伪造交付，不读取环境里的 API key，不发起模型请求。没有安装或启用付费回退提供方。

`local` 提供方是可复核的确定性工具：整理用户输入、文本/CSV 统计、生成真实文件。它不是语言模型，不联网研究，不智能编写代码，不对材料真实性背书。代码文件是安全的本地输入统计脚本；网页项目是封装原始材料的 HTML/ZIP，不冒充 AI 开发完成的业务软件。

模型接入页显示核验状态、注册状态、OAuth 状态、文档链接和调用记录。执行器已支持授权阻断、额度暂停状态、轮次上限、每日上限和并发限制；真实供应商额度异常的映射仍需授权后验证。

## 接入后必须补验

1. 阅读并存档官方最新条件，确认该项目的开源资格和应用注册要求。
2. 使用本人获准的应用注册信息和官方回调地址；不得复用其他产品的 client_id。
3. 按官方文档实现 OAuth Authorization Code + PKCE（若官方要求），随机 state、S256、单次回调、防重放、服务端会话隔离、令牌安全存储和撤销。
4. 仅使用官方明确支持的 Responses 授权与端点；不抓取网页、不提取 Cookie、不使用非官方接口。
5. 至少三名员工完成一次真实模型任务；验证 token/额度记录、额度用尽暂停、错误恢复和无付费回退。

本仓库不提供假 OAuth 按钮，也不将尚未核实的授权流程标记为已完成。
